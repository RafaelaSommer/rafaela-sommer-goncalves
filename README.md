**Tecnologia principal:** Python

## 🤖 GitHub Profile Auto Updater

Projeto criado para automatizar a atualização do perfil do GitHub.

A aplicação utiliza **JavaScript + GitHub Actions** para atualizar automaticamente informações e estatísticas do perfil, reduzindo a necessidade de manutenção manual.

**Tecnologias:**

* JavaScript
* GitHub Actions
* Automação
* GitHub API

🔗 [Ver projeto no GitHub](https://github.com/RafaelaSommer/GitHub-Profile-Auto-Updater)

---

## 💳 Card Validator Senior

Sistema de validação de cartões desenvolvido utilizando tecnologias modernas para criar uma solução completa.

O projeto utiliza:

* Node.js
* React
* Algoritmo de Luhn
* API REST

O objetivo é validar informações e identificar bandeiras de cartões de forma estruturada.

🔗 [Ver projeto no GitHub](https://github.com/RafaelaSommer/card-validator-senior)
